# 2026 mission variant - EXPERIMENTAL, NOT VALIDATED

`main_2026_mission_web.cpp.txt` is an **unfinished 2026 experiment**: an 8-state autonomous mission machine with a web start/stop page. The 2026 autonomous mission was **never completed**.

- It is **not** the firmware used in the 2025 competition. The 2025 competition firmware belongs to the 2025 generation (`../../../2025_teknofest_mission/`; the exact flashed file is still unidentified).
- It is not built by PlatformIO (`.txt` extension), was not compiled or run during the audit, and has no test records.
- Its turn manoeuvre (+180 deg) differs from the 2025 code (+150 deg); this has not been reconciled or validated.
- Kept only to document the development path. Do not treat it as a working or deployed system.
